# Kit de marca Kalza

Archivos generados con `node tools/generar-logo.js`. Si cambiás la geometría o
los colores en ese script, volvé a ejecutarlo y se regeneran todos.

## Cuál usar

| Archivo | Para qué |
|---|---|
| `kalza-avatar-1024.png` | **Foto de perfil.** Instagram, Facebook, TikTok, WhatsApp Business. |
| `kalza-avatar-512.png` | Lo mismo, más liviano. Sirve donde pidan 512 px. |
| `kalza-avatar-accent-1024.png` | Versión naranja, para campañas o destacados. |
| `kalza-avatar-claro-1024.png` | Azulejo claro con K negra: para fondos oscuros. |
| `kalza-k-negra-1024.png` | Monograma suelto, fondo transparente. Marcas de agua, sellos, cajas. |
| `kalza-k-crema-1024.png` | Igual pero en crema, para poner sobre fotos o fondos oscuros. |
| `kalza-favicon-256.png` | Ícono de pestaña, por si algún servicio no acepta SVG. |
| `kalza-mark.svg` | El azulejo en vectorial. **Usalo siempre que puedas**: no pierde calidad. |
| `kalza-logo-horizontal.svg` | Logo completo: monograma + palabra KALZA. Para encabezados y facturas. |
| `kalza-logo-horizontal-oscuro.svg` | El mismo lockup sobre fondo negro. |

## Colores

| Nombre | Hex | Uso |
|---|---|---|
| Tinta | `#111110` | Fondo del azulejo, textos |
| Papel | `#faf8f4` | La K, fondos del sitio |
| Acento | `#e8471f` | Detalles, ofertas, enlaces activos |

## Reglas de uso

- Dejá siempre un margen libre alrededor del logo de al menos la mitad del
  ancho del azulejo. No lo pegues al borde ni a otros elementos.
- No lo estires: mantené la proporción cuadrada del azulejo.
- No cambies los colores fuera de las variantes que ya están acá.
- Para tamaños chicos (menos de 32 px) usá el azulejo, no la K suelta.

## Nota sobre el logo horizontal

La palabra KALZA en los SVG usa la tipografía **Archivo** en peso 900. Si el
equipo donde se abre no la tiene instalada, cae a Helvetica o Arial y se ve
levemente distinta. Para un uso definitivo (imprenta, cartelería) conviene
convertir ese texto a curvas desde un editor vectorial.
